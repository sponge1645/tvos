# Состояние проекта — ветка 1.1.2

Кандидат подготовки релиза: **1.1.2 (1B201)**. Публикация APK и OTA ещё не выполнена.
Документ описывает текущее состояние; история прежних сборок остаётся в Git.

## Выполненная чистка

- Удалены недоступный встроенный поиск Home и его слои/обработчики.
  Используется отдельный `SearchActivity` с общим `SearchController`.
- Переходы фокуса между погодой, верхними кнопками, постерами и доком выделены
  в `HomeNavigation`; управление нажатиями и удержаниями сохранило своих владельцев.
- Данные списков выбора настроек выделены в `SettingsPicker`. Загрузка приложений
  и ТВ-провайдеров имеет отдельные обработчики с отменой при выходе.
- Категории и верхние кнопки используют общий `SettingsOrderEditor` и общий путь
  отрисовки; строка VPN сохраняет особое поведение.
- `DockContinueArtwork` владеет загрузкой постеров/логотипов и окном кеша;
  `DockContinue` — фокусом, прокруткой, анимациями и отрисовкой ряда.
- Проверки поколений запросов предотвращают применение старых результатов.
  Отменённая загрузка не запускает следующий этап получения логотипа.
- Диагностика изображений выключена по умолчанию. Её можно включить через
  `adb shell setprop log.tag.tvOS-Artwork DEBUG`; ссылки и токены не выводятся.
- Старые обработчики громкости через ADB и глобальный accessibility-фильтр кнопок
  удалены. Текущий путь назначения кнопок описан в [REMOTE-SHORTCUTS.md](REMOTE-SHORTCUTS.md).

## Жизненный цикл экранов

- Успешное сохранение аватара уведомляет UI даже при обрыве HTTP-ответа телефону.
- Поиск освобождает окно постеров на паузе, отклоняет старые результаты карточки
  и возобновляет незавершённую загрузку при возвращении без сброса позиции.
- Отмена метаданных ряда продолжения просмотра закрывает активное HTTP-соединение
  вне UI-потока. Старые события открытия/закрытия не меняют владельца нового запроса.

## Настройки экрана «Домой»

Пункт управления и экран «Домой» → Экран «Домой»:
- Вид: Подборка / tvOS-вид.
- Вид карточек: Продолжить просмотр / Рекомендации; доступен только для tvOS-вида.
- Разделы для подборки: Новинки, Фильмы, Сериалы, Я смотрю; доступны только для Подборки.

Смена вида сохраняет порядок/видимость разделов и выбранный вид карточек.
Списки выбора используют галочку; возврат восстанавливает исходный пункт и прокрутку.
Погода → Показывать: Нет / На экране «Домой» / На нижней панели / Оба.

## Подбор изображений

Обычный KinoPub и мод используют общий путь. Оригинальное название читается отдельно.
Отсутствующий год восстанавливается через autocomplete по точному ID KinoPub, с ограничением
ответа и отменой соединения; успешные годы кешируются в памяти. Числовой ID источника
никогда не используется как ID TMDB. Точный год имеет приоритет. Расхождение на один год
допускается лишь для единственного кандидата с обоими названиями и нужным типом.
Индивидуальные подстановки года для «Сумерек» и Buddy удалены.

## Подготовка выпуска

APK получает `assets/build-info.json` при сборке. Подготовка релиза сверяет его с исходниками
и читает фактические пакет/версию APK через `aapt2 dump badging` до копирования файлов.
Старый APK или несовпадающие версии отклоняются. Номер сборки не вычисляется из Git.
Инструкции: [RELEASING.md](RELEASING.md).

## Изображения и кеш

| Данные | Лимит на диске | Дополнительные ограничения |
| --- | --- | --- |
| Постеры | 200 MiB в общем каталоге | 12 MiB декодированных изображений на экземпляр кеша |
| Фоновые изображения дока | 96 MiB | 96 файлов |
| Фоны рекомендаций | 96 MiB | 48 файлов |

Суммарный лимит сжатых файлов этих каталогов — 392 MiB без активных временных
загрузок. Возраст сам по себе не удаляет изображение: вытесняются наименее недавно
использованные файлы при превышении лимитов. Наличие файла не гарантируется после
очистки кеша пользователем или системой. Новым URL может понадобиться сеть.

Ряд продолжения просмотра держит окно до четырёх постеров и четырёх необязательных
логотипов. Для широких TMDB-постеров используется `w780`. Подбор учитывает название,
тип, доступный год и данные издателя; при отсутствии подходящего широкого изображения
сохраняется запасной вариант из истории. Доступность внешнего изображения не гарантируется.

## Проверено

Полный локальный набор содержит **168** сценариев `tests/test_*.py` на JDK 17.
Устаревший тест индивидуальных поправок названий удалён вместе с этими поправками.
CI запускается при push в `main` и `1.1.2`: тесты, строгая компиляция APK, DEX,
проверка ресурсов и тестовой подписи; отдельные задания проверяют JDK 21 и 25.
Результат текущего CI нужно проверять по конкретному коммиту, а не по старой сборке.
Тесты используют платформенные адаптеры и не заменяют настоящий ТВ.

## Оставшиеся проверки

- На телевизоре: холодное открытие погоды, поиск и его история, вход/выход настроек,
  фокус и запуск карточек продолжения просмотра, обе темы, сон/возврат и работа пульта.
- На устройстве: поведение без сети и после её восстановления, очистка/вытеснение кеша,
  потребление памяти, время кадров и особенности OEM/HDMI-CEC. Улучшение FPS/PSS не измерено.
- На Android 11+ проверить список приложений, выбор ТВ-провайдера, клавиатуры,
  назначение кнопок и источники истории после удаления дублирующего `<queries>`.
  `QUERY_ALL_PACKAGES` сохранён: `LiveTvTargets` использует `getInstalledPackages`,
  а лаунчер обнаруживает приложения и проверяет пакеты. Точечный список пакетов и
  intent-сигнатур не расширял видимость сверх этого разрешения.
  Основание: [Manifest.permission.QUERY_ALL_PACKAGES](https://developer.android.com/reference/android/Manifest.permission#QUERY_ALL_PACKAGES)
  и [объявление видимости пакетов](https://developer.android.com/training/package-visibility/declaring).
  Разрешение видимости не предоставляет доступ к закрытым данным провайдеров;
  `READ_TV_LISTINGS` и остальные разрешения сохранены.
- Доступность клавиатурного переключения через локальный ADB и системные экраны
  остаётся зависимой от прошивки; ограничения описаны в документации пульта.

Размер класса сам по себе не требует дальнейшего разделения. Следующие изменения
должны решать конкретную проблему ответственности, повторения или измеренной нагрузки.

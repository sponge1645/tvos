# Состояние проекта — ветка 1.2

Кандидат релиза: **1.2 (1C248)**, Android versionCode **11**.

- Полный локальный прогон тестов и сборка прошли. CI исходников сборки 1C248 зелёный.
- Рабочая подпись находится на Mac владельца. Локальные CI APK для выпуска не подходят.
- Release и OTA 1.2 ещё не опубликованы.
- Список пользовательских изменений: [releases/1.2.md](releases/1.2.md).
- Порядок сборки и публикации: [RELEASING.md](RELEASING.md).

## Проверки на реальных телевизорах

Остаются отдельными от автоматических тестов: баннеры на Android 9,
недоступные специальные возможности, удержание громкости с перехватом,
отмена/ошибка/повтор установки при откате TizenTube.

## Ограничения

- Перехват системных кнопок и ADB зависят от прошивки и доступных разрешений.
- Размеры приложений без доступа к статистике показываются как «—».
- Удаление при откате TizenTube необратимо для данных приложения; сохраняется возможность повторной установки APK.
- Переход в карточку Кинопоиска зависит от доступного соответствия; поиск служит запасным вариантом.

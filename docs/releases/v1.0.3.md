# tvOS 1.0.3 — подготовка

Первая тестовая сборка исправлений для старых Android.

- На Android 9–10 переходы предпросмотра и содержимого заставки используют покадровый fade по монотонному времени вместо зависимости от системного PropertyAnimator.
- Для системного окна DreamService на Android 9–10 добавлены собственные вход и выход через прозрачность окна; каждая фаза длится 600 мс с одинаковым ускорением/замедлением.
- Отмена перехода сохраняет текущую прозрачность; закрытие и остановка отменяют отложенные кадры. Запоздалый старт после пробуждения не запускает вход заново.
- Android 11+ сохраняет существующий путь анимации. Apple, Google и National Geographic используют общую подложку перехода.

- В разделе «Об устройстве» IP и тип подключения берутся из физической сети Ethernet/Wi-Fi, исключая VPN даже при наличии у него транспортов Wi-Fi/Ethernet. Адрес туннеля больше не подменяет локальный адрес телевизора. Запросы состояния сети ограничены одним разом в секунду.

Версия Android: `1.0.3`, `versionCode=6`. Это кандидат для проверки, не опубликованный релиз.

## Проверка на Xiaomi Android 9

Для каждого источника проверить предпросмотр и запуск по таймеру, вход и выход любым навигационным действием, быстрый выход во время появления, повторный предпросмотр и уход из настроек во время затемнения. Проверить отсутствие чёрного экрана и сохранение звука/управления после закрытия. Записать значения системных `window_animation_scale`, `transition_animation_scale`, `animator_duration_scale`; код не меняет эти настройки. Отдельно проверить Android 11+ на отсутствие регрессий.

Сборка и JVM-тесты не подтверждают визуальный результат на реальном Xiaomi. Исправление подготовлено по коду и наблюдениям пользователя; точная причина на прошивке ещё не установлена. Если прошивка принудительно снимает окно заставки, она может прервать выходной fade.

Исправления BootGuard и автоматическое снятие restricted settings остаются в плане 1.1.

Пользователь подтвердил плавный вход и выход заставки на Xiaomi Android 9 для первой сборки. Исправление IP требует проверки на Ethernet и Wi-Fi с включением/выключением VPN.

## Кнопка сети в Menu Bar

Между настройками и часами добавлена кнопка с тремя состояниями: Wi-Fi с интернетом, Ethernet с интернетом, нет интернета (перечёркнутый Wi-Fi). Физический тип подключения выбирается отдельно от VPN; наличие интернета определяется по системному NET_CAPABILITY_VALIDATED активной сети. Это отражает оценку Android, не гарантирует доступность каждого сайта. Кнопка открывает системные настройки сети; на прошивках без соответствующей активности используется экран Wi-Fi или общие настройки.

Наблюдение за сетью работает только пока главный экран виден и освобождается при уходе. Нет отдельных ping/HTTP-проверок. Кнопка доступна пультом и TalkBack, в том числе когда отключены все необязательные кнопки верхней панели.

Проверка: Wi-Fi и Ethernet с интернетом; роутер без интернета; отключение кабеля/сети; включение VPN; смена типа подключения; открытие/возврат из настроек; скрытые часы и настройки; отсутствие накопления callbacks после повторных переходов.

## Пустая выдача поиска и список приложений

- При переходе из Dock вверх в пустом поиске фокус выбирает видимое верхнее действие вместо скрытой вкладки категории. Навигация и повторный вход в поиск доступны без обязательного Back.
- «Все приложения» больше не исключает известные приложения Dock и приложения источников. Для известных установленных и включённых приложений добавлен запасной поиск по пакету и launch intent, без дублей.
- Настройки ТВ представлены одной карточкой с системным ACTION_SETTINGS, даже если прошивка не публикует launcher activity. При отсутствии обработчика не создаётся неработающая карточка.
- Отключённые приложения не включаются автоматически. Существующий список скрытых служебных/рекламных приложений сохраняется.

## Порядок кнопок правого угла

В «Настройки → Верхняя панель → Кнопки» добавлен редактор по образцу категорий и Dock: OK включает/выключает, стрелки влево/вправо перемещают включённые кнопки. В списке: Поиск, ТВ, VPN, Настройки, Сеть, Часы. Включённые строки пронумерованы, выключенные находятся ниже. Отдельный пункт «Приложение VPN» сохраняет доступ к выбору VPN-приложения.

Сохранённый порядок применяется к расположению кнопок, движению пульта, переходам с постеров и порядку TalkBack. Часы с профилем можно перемещать как обычную кнопку; их ширина учитывается при размещении. Старые переключатели сохраняются, прежний порядок используется по умолчанию. При скрытой кнопке «Сеть» наблюдение за сетью не запускается. При скрытии всех кнопок и категорий фокус остаётся в Dock.

## Значки и ширина поиска

Капсула ввода поиска уменьшена на 20% по ширине и остаётся по центру. Для кнопки сети используются предоставленные пользователем PNG `wifi.png`, `ethernet.png` и `nonetwork.png` через общий кеш Symbols с цветом и увеличением фокуса. Прежние рисованные значки удалены; остальные изображения архива совпадают с текущими.

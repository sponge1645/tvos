# tvOS 1.0.3

- Плавные вход и выход заставки на Android 9–10, включая предпросмотр и запуск по таймеру.
- Правильный локальный IP Ethernet/Wi-Fi в настройках при включённом VPN.
- Кнопка «Сеть» в верхней панели: Wi-Fi, Ethernet и отсутствие интернета; нажатие открывает системные настройки сети.
- Настройка порядка и видимости кнопок верхней панели по образцу Dock и категорий. Можно перемещать «Сеть» и часы; настройки приложения VPN доступны отдельным пунктом.
- Исправлено возвращение фокуса к верхним кнопкам из пустой выдачи поиска.
- В «Все приложения» возвращены приложения из каталога Dock и источников; добавлен запасной поиск известных приложений по пакету и отдельная карточка настроек ТВ.
- Капсула поиска стала на 20% уже. Добавлены новые значки Wi-Fi, Ethernet и отсутствия интернета.

Android versionCode: 6. Для обновления поверх предыдущей версии используется прежняя подпись приложения.

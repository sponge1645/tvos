# tvOS 1.1.2 — кандидат 1B201

Статус: подготовка; GitHub Release и OTA ещё не опубликованы.

- Поиск: заголовки Bold, отмена загрузок на паузе, восстановление карточки при возврате.
- Экран «Домой»: явные виды Подборка/tvOS; отдельный выбор карточек и разделов.
- Рекомендации Dock: пробное открытие показанного фильма удержанием ↑, если источник передаёт ссылку.
- Настройки: единые галочки выбора, восстановление фокуса и прокрутки в меню пульта.
- Погода: четыре варианта показа, включая «Нет», с соответствующими подсказками.
- KinoPub и мод: оригинальное название и год по точному ID для подбора изображений.
- Аватар: обновление на ТВ даже при обрыве ответа телефону после сохранения.
- Фоновые загрузки: отмена соединений и защита от устаревших результатов.
- Подготовка выпуска: сверка версии APK с исходниками до формирования метаданных.

Нужна финальная проверка на телевизоре и сборка с рабочей подписью.

# Проверка OTA

Опубликованные 1.0.1 (code 3) и 1.0.2 (code 4) имеют одинаковый сертификат, корректные версии, размеры и SHA-256. Установленная у пользователя 1.0.1 также имеет этот сертификат. Ручная установка 1.0.2 проходит. Точное условие, отвергаемое старым встроенным проверяющим кодом, пока не установлено.

В этой ветке загрузчик запрашивает обе формы сертификатов Android и использует legacy-поле только при отсутствии текущего набора в SigningInfo. Непустой текущий набор имеет приоритет. Подмена пакета, версии, ключа или добавление подписанта по-прежнему блокируются. Отдельные ошибки различают отсутствие метаданных, несовпадение версии, отсутствие сертификатов и другое имя подписанта.

## Сквозная проверка с 1.0.1

На эмуляторе должна оставаться установленная 1.0.1. Запустить `bash tools/test-ota-from-1.0.1.sh` из проекта с прежним config.properties и freemytv.keystore. По умолчанию используется adb -e; для конкретного устройства можно задать TVOS_ADB_SERIAL.

Скрипт собирает тестовый клиент с кодом этой ветки, но версией 1.0.1 / code 3, в отдельном временном каталоге. Устанавливает его поверх существующей 1.0.1 с сохранением данных и открывает настройки. Затем пользователь запускает обновление до неизменённой опубликованной 1.0.2 кнопкой внутри приложения. При ошибке нужен её точный текст.

Скрипт не удаляет приложение, не понижает версию, не заменяет исходный манифест или релизные APK в рабочем проекте. Временные копии ключа и исходников удаляются при завершении. При установленной 1.0.2 скрипт останавливается до сборки и установки.

Это проверка, а не новый опубликованный выпуск. main, теги и файлы релизов 1.0–1.0.2 не изменяются. Успешный переход ещё требует проверки на эмуляторе/телевизоре. После подтверждения исправленный загрузчик нужно включить в следующий выпуск; исправление только в целевом APK не изменяет код проверки уже установленного старого клиента.

# Проверка перехода OTA

Прежний helper, пересобиравший 1.0/1.0.1 из новых исходников, удалён: он не подтверждает реальный переход ключей.

Нужна отдельная тестовая установка настоящей стабильной 1.0.3 со старым сертификатом. Не пытайтесь установить мост versionCode 7 поверх dev-версии с большим versionCode.

Проверить по шагам:

1. 1.0.3 видит максимум 1.0.4 через legacy Latest.
2. 1.0.4 устанавливается поверх 1.0.3 со старым ключом без удаления данных.
3. 1.0.4 проверяет ota-v1 и принимает 1.1, подписанную новым ключом с корректным lineage.
4. Android устанавливает 1.1 без удаления данных; следующая проверка OTA работает.
5. Повторить на Android 9, 11 и 13+, включая прошивки со старым представлением сертификатов.

Подробнее: [KEY-ROTATION.md](KEY-ROTATION.md). Тестовый APK CI для этой проверки не подходит.

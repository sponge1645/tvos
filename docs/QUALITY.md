# Проверки качества и оптимизация

## dev.12

- Все предупреждения Java видимы: `-Xlint:all,-options`. Исключена только категория
  уведомлений о выбранном source/target 8. В CI на JDK 17 / Android SDK 34 включён
  `TVOS_STRICT_JAVA=1`: новое неподавленное предупреждение завершает сборку ошибкой.
  Это проверки javac, а не Android Lint. Локальная сборка показывает предупреждения,
  но допускает более новые SDK/JDK; строгий режим можно включить той же переменной.
- На исходном коде найдено 20 deprecation-предупреждений. Старые API оставлены для
  совместимости/сохранения проверенного поведения и отмечены на конкретных полях
  или методах с причиной. Не использовать глобальный `-nowarn` или подавление всех
  категорий. Аннотации здесь не означают, что будущая миграция API не нужна.
- `Recs`: ожидаемые IO/JSON-ошибки обрабатываются отдельно. Неожиданные runtime-сбои
  на границах загрузки диагностируются и сохраняют старые fallback-сценарии.
  Диагностика выводит операцию, типы и ограниченное число кадров стека/причин;
  сообщения исключений и ответов туда не включаются. OOM остаётся обработан на
  границах подготовки изображений. Общую замену исключений в других подсистемах
  не делать без проверки API и прежнего поведения.
- Исправлен подтверждённый повторный пересчёт фирменных All Apps карточек:
  очистка теперь распознаёт префикс ключа и сохраняет карточки установленных
  пакетов. Тесты проверяют идентичность bitmap после очистки и удаление выбывшего
  пакета. FPS/CPU на телевизоре этим тестом не измеряются.
- 78 пар строк настроек перенесены в `values/settings_strings.xml` и `values-ru/`.
  Выбор контекста описания остаётся в `SettingsContent`; `AppStrings` использует
  application context и отдельные кеши EN/RU. Они содержат только обычные строки
  без конфигурационных вариантов кроме языка. Тесты проверяют оба направления
  несовпадения системного/выбранного языка и отсутствие повторных ресурсовых
  обращений; 34 776 комбинаций совпали с исходными Java-строками.

## Продолжение локализации dev.13

В ресурсах теперь 178 пар строк настроек и plural-ресурс относительного времени.
SettingsActivity использует XML для собственных текстов значений, диалогов,
поиска города и озвучивания; язык выбирается приложением. Шаблон даты тоже в XML.
Неизменяемые имена брендов и самоназвания языков остаются литералами. Значение
пользовательского имени устройства по умолчанию «ТВ» сохранено, чтобы миграция
переводов не меняла пользовательские данные.

Сохранённые диагностические уведомления приходят из других подсистем как текст;
их прежний Russian.text остаётся до отдельной миграции производителей сообщений.
getQuantityString использует те же кешированные Resources; сама переменная
plural-строка не кешируется по каждому числу. Тесты проверяют реальные методы
SettingsActivity с XML-адаптером; этот адаптер не заменяет Android-проверку форм
на устройстве. Компилированная таблица APK проверяется отдельно через aapt2.

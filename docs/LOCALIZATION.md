# Локализация tvOS

AppLanguage задаёт поддерживаемые языки, коды, локали, самоназвания, порядок выбора и форматы. Сейчас доступны RU/EN. Переводы находятся в home_strings.xml, settings_strings.xml, runtime_strings.xml и weather_strings.xml внутри values/values-ru. AppStrings.get читает текущий язык; явный AppLanguage позволяет формировать языковой снимок. Кеши используют EnumMap, системная Locale не изменяется.

## Сообщения и ошибки

С dev.22 Russian.java и legacyText удалены. Жанры получают ресурсы напрямую. ResourceFailure переносит код известной ошибки ADB; неизвестные сообщения ОС сохраняются как данные. Новые уведомления HomeMode используют resource ID в процессе, но сохраняют строковое имя ресурса в message.key и параметры в message.args. Числовые R ID не сохраняются. Вложенные ошибки и списки тоже хранят ключи, а не переведённые строки.

NoticeText отражает каталог собственных R.string один раз и индексирует имена/шаблоны. Он мигрирует старые записи при чтении состояния; рендерер затем обращается по ключу. Старые даты, порядок и дополнительные поля сохраняются. Неизвестные тексты остаются raw, а исходный text служит резервом при отсутствующем ключе. Миграция сохраняется следующей обычной записью HomeMode; UI polling не записывает устаревший снимок обратно.

Если будет добавлен R8/shrinking, потребуется сохранить имена полей R.string для индекса. Текущая сборка использует javac/D8 без shrinking. Изменение имени ресурса требует учитывать сохранённые ключи; старый text остаётся резервом.

## Следующий язык

Добавить запись AppLanguage и XML values-xx с теми же ключами и нужными plural-формами. Расширить JVM-адаптеры и сверку компилированных строк, сейчас проверяющие утверждённые RU/EN. Проверить шрифты, переносы и озвучивание на ТВ. Названия внешних сервисов, пользовательские имена и непрозрачные диагностические данные не переводятся автоматически.

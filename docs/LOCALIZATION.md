# Локализация tvOS

## Где менять языки

`app/src/io/tvos/AppLanguage.java` — единственный реестр доступных языков:
код в настройках, самоназвание, Locale, полная дата, час прогноза.
Из Locale получается тег TMDB; порядок enum задаёт порядок переключения.
Текущий выбор кешируется в реестре, а Prefs отвечает за сохранение и уведомления
каталога/города. Ui.applyLanguage синхронизирует совместимые флаги старых классов.

Тексты хранятся в Android XML по локалям:
- `app/res/values/home_strings.xml`, `settings_strings.xml` — английский;
- `app/res/values-ru/home_strings.xml`, `settings_strings.xml` — русский.

Не нужно собирать переводы всех языков в одну огромную Java-таблицу.
В основном UI используется `AppStrings.get(R.string.key)`.
Явный снимок или тест может передать `AppLanguage` вторым аргументом.
Plural-шаблоны выбираются теми же локализованными Resources.
Кеши строк, ресурсов и вкладок используют enum-ключи; фиксированных RU/EN-индексов нет.

## Как добавлять следующий язык

1. Добавить запись в AppLanguage с кодом, самоназванием, Locale и шаблонами.
2. Подготовить соответствующие `values-xx` XML с теми же ключами и нужными plural-формами.
3. Перенести/проверить оставшуюся Java-копию других подсистем: сейчас часть строк
   HomeData, Recs, профиля, заставок и сохранённых уведомлений ещё использует
   совместимые ru/en-флаги или старый Russian.text. Одна новая запись не переводит их.
4. Расширить языковые JVM-адаптеры и проверки компилированных строк, которые сейчас
   намеренно проверяют утверждённые RU/EN. Проверить шрифты, переносы, фокус и озвучивание на ТВ.

В dev.19 добавления языка нет: сохранены RU/EN, прежние коды настроек,
порядок переключения и английский fallback старых неподдерживаемых значений.
Системная Locale не изменяется. Фиксированные Locale.US в машинных форматах API,
координат и рейтинга остаются отдельными от пользовательского языка.

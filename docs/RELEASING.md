# Публикация tvOS

На соответствующей ветке выполните:

```sh
./release.sh 1.1
python3 tools/publish-release.py
python3 tools/publish-release.py --publish
```

Версию указывайте согласно выпускаемому релизу.

GitHub Latest содержит актуальный стабильный APK.
Его legacy-манифест направляет старые версии на 1.0.4.
Для версий 1.0.4+ используется канал `ota-v1`.

Проверяйте APK перед публикацией.
Не публикуйте приватные ключи и локальные настройки.

# Выпуски tvOS

Репозиторий: https://github.com/sponge1645/tvos

## Первый выпуск 1.0

1. Примените эти исходники к своему рабочему проекту. Сохраните текущие config.properties и freemytv.keystore.
2. Выполните `./build.sh && adb install -r tvOS.apk`.
3. Откройте https://github.com/sponge1645/tvos/releases/new.
4. Создайте тег `v1.0`, название `tvOS 1.0`, ветка `main`.
5. Прикрепите **оба файла**: `release/tvOS.apk` и `release/update.json`.
6. Нажмите Publish release. Не отмечайте pre-release. Выпуск должен быть Latest.

До первого выпуска проверка покажет, что выпуск или файл обновления ещё не опубликован.
После публикации 1.0 лаунчер версии 1.0 должен показать, что он актуален.

## Следующая версия

Внесите изменения в код, затем выполните `./release.sh 1.0.1`.
Скрипт увеличит Android versionCode, соберёт подписанный APK и подготовит два файла в release/.
Сохраните изменения исходников (включая новую версию в манифесте) в репозитории до создания выпуска.
Создайте выпуск `v1.0.1` и прикрепите новые `tvOS.apk` и `update.json` из одной сборки.
Не заменяйте файлы уже опубликованного выпуска; используйте новую версию и тег.

Если GitHub CLI установлен и вы вошли в свой аккаунт, после загрузки исходников можно опубликовать:

```bash
gh release create v1.0.1 release/tvOS.apk release/update.json --repo sponge1645/tvos --title 'tvOS 1.0.1' --notes 'Описание изменений' --latest
```

## Как работает обновление

- Кнопка «Обновление ПО» проверяет update.json последнего стабильного выпуска.
- «Загрузить и установить» скачивает APK из указанного тега, проверяет размер, SHA-256, пакет io.tvos, versionCode/versionName и совпадение текущих сертификатов подписи.
- Затем открывается системный установщик Android. При необходимости разрешите tvOS установку из этого источника и выберите «Установить» повторно.
- Автоматическое обновление проверяет выпуск не чаще раза в сутки, пока главный экран/настройки активны, и скачивает новую версию. Установка требует подтверждения на ТВ.
- Сервер/VPS, GitHub-токен в приложении и отдельное приложение GitHub на телевизоре не нужны.
- Ключ подписи не меняйте. Осознанная ротация сертификата этим вариантом загрузчика не поддерживается.

## Что не публиковать

freemytv.keystore, config.properties, out/, резервные копии и личные токены.
CI проверяет сборку с одноразовым ключом и не выпускает APK для пользователей.

## Нумерация версий

Исправления и небольшие улучшения: 1.0.1, 1.0.2 и далее.
Крупные обновления с новыми функциями: 1.1, 1.2 и далее.
Android versionCode увеличивается с каждым опубликованным обновлением независимо от видимого формата версии.

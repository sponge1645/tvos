# Выпуски tvOS

Репозиторий: https://github.com/sponge1645/tvos

Актуальный порядок подписи и перехода: [KEY-ROTATION.md](KEY-ROTATION.md).

- 1.0.4 — мост со старым ключом, GitHub Latest.
- 1.1+ — новый ключ с lineage, никогда не GitHub Latest; манифест обновляется в ota-v1.
- Версия 1.0.4 автоматически выбирает старый ключ; остальные выбирают новый из signing.local.json. Обычная сборка не генерирует ключ.

На Mac владельца один раз выполнить `python3 tools/signing.py init` и сохранить защищённую резервную копию `~/.local/share/tvos-signing`.

Для выпуска:

```bash
./release.sh 1.0.4  # либо 1.1 на соответствующей ветке
python3 tools/publish-release.py  # подготовить draft
```

После проверки draft и установки на тестовое устройство:

```bash
python3 tools/publish-release.py --publish
```

Helper публикует с нужным флагом Latest и обновляет отдельный OTA-манифест. Если нужно повторно обновить только канал уже опубликованного релиза: `python3 tools/publish-release.py --update-channel`.

APK и update.json берутся из одной подписанной сборки. Проверяются размер, SHA-256, пакет io.tvos, версия и совместимость сертификатов; Android окончательно проверяет подпись при установке. Сохранённые данные должны проверяться на настоящем переходе с 1.0.3.

В GitHub не отправляются signing.local.json, ключи, пароли, lineage владельца, config.properties, out/, резервные копии и токены. CI использует только одноразовые ключи и не публикует APK.

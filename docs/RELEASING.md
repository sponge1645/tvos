# Подготовка и публикация tvOS 1.2

Кандидат: **1.2 (1C248)**, Android versionCode **11** (у 1.1.2 — 10).
Исходники находятся в ветке `1.2`. Проверки сборки 1C248 прошли локально и в CI.
Рабочий APK и OTA не публикуются из CI: там используется одноразовый ключ.

## Проверка и сборка

На Mac нужны сохранённые `config.properties`, `signing.local.json` и рабочие ключи.
После применения исходников выполнить:

```sh
TVOS_SIGNING_MODE=release ./release.sh 1.2
adb install -r tvOS.apk
```

Скрипт проверяет подпись на Android API 28/30/33/34, соответствие APK исходникам,
ресурсы, размер и SHA-256. Готовит `release/tvOS.apk` и `release/update.json`.
Релиз не требует удаления tvOS: рабочая подпись сохраняет обновление поверх 1.1.2.

На реальных ТВ проверить Android 9: смену баннеров при быстром листании;
отсутствие рестарта при недоступных специальных возможностях; удержание громкости
при включённом перехвате; откат TizenTube, отмену и повтор установки.
Эти проверки нельзя заменить тестами с имитацией Android.

## Публикация

Использовать точный SHA коммита, из которого получены исходники APK, чтобы тег
не попал на старый `main`. Дождаться зелёного CI этого коммита.

```sh
python3 tools/publish-release.py --target <40-символьный-SHA-коммита>
python3 tools/publish-release.py --publish
```

Первый вызов создаёт черновик с названием **tvOS 1.2**, APK, legacy-манифестом
и описанием из [releases/1.2.md](releases/1.2.md). Второй публикует Latest и
обновляет `ota-v1`. Legacy-манифест Latest остаётся мостом на 1.0.4;
современный манифест направляет на APK 1.2. Не заменять legacy-манифест вручную.

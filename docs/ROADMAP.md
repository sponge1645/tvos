# План tvOS 1.1

Разработка начата в ветке `dev-1.1` от стабильной 1.0.3. Текущая тестовая сборка — `1.1.0-dev.3`; последующие пункты выполняются отдельно, без публикации стабильного релиза до проверки.

## Этап 1 — векторные symbols

- [x] Использовать согласованные 34 SVG из набора вместо PNG для значков интерфейса, сети и погоды.
- [x] Кэшировать векторные контуры, рисовать их в текущем масштабе, сохранить размеры, выравнивание, цвет и исходную полупрозрачность.
- [x] Сохранить общие тени погоды во всех трёх заставках; прозрачная маска строится из SVG в фактическом размере значка при обновлении значка погоды.
- [x] Первая визуальная проверка SVG пользователем на сборке dev.1.
- [ ] Проверить на реальных Android 9 / 11 / 13+ и оценить плавность увеличения значков.
- Цветные `logos` в этот этап не входят. PNG из `symbols` остаются только резервом, если SVG недоступен или содержит неподдерживаемую конструкцию.

## Приложение по умолчанию

## Продолжить просмотр

Продумать раздел с последними пятью фильмами или сериалами из каждого приложения, предоставляющего историю просмотра. В первую очередь проверить Seena и KinoPub. Показывать постер, название, сезон и серию; нажатие должно открывать нужное приложение и, при поддержке интеграции, продолжать с нужного места.

## Случайная карточка в категориях

- В конце всего списка постеров категории добавить постер с игральным кубиком и подписью «Случайный фильм».
- По нажатию этот же постер превращается в карточку случайного произведения из текущей категории: фильма в «Фильмах», сериала в «Сериалах», детектива в «Детективах».
- Выбирать только фильмы и сериалы с рейтингом 6,5 или выше.
- Добавить такую карточку во все категории, кроме «Новинок»; текущий перечень — «Фильмы», «Сериалы», «Детективы».
- Пока это идея для 1.1, без реализации в 1.0.2.

## «Уже смотрел» в режиме «Случайный фильм»

- Добавить к результату случайного выбора кнопку «Уже смотрел».
- Отмеченный фильм исключать из последующих случайных выборов, в том числе после перезапуска приложения и обновления tvOS.
- Хранить отметки в постоянных данных приложения отдельно от кеша постеров и подборок. Очистка кеша не должна удалять эту историю.
- Идентифицировать произведение по стабильному ID и типу, а не по локализованному названию.
- Включить историю отметок в будущую резервную копию. Полный сброс данных приложения удаляет локальную историю; восстановление возможно из резервной копии.
- Пока только план для 1.1.

## Специальные возможности после обновления

- На Android 13 и новее проверить сценарий блокировки специальных возможностей ограниченными настройками после установки или обновления APK.
- При включении специальных возможностей самим пользователем использовать встроенный ADB: проверить `ACCESS_RESTRICTED_SETTINGS` и при блокировке выполнить `cmd appops set io.tvos ACCESS_RESTRICTED_SETTINGS allow`, затем продолжить включение службы и проверить результат. Применять только к пакету tvOS, не затрагивая другие службы.
- Автоматическое исправление доступно при включённой отладке и авторизованном ADB-подключении к телевизору. Если подключение недоступно или команда не поддерживается прошивкой, показать понятную инструкцию вместо ложного сообщения об успехе.
- Учесть подтверждённый случай AI POINT на Android 14: переключатель сразу выключался, `ACCESS_RESTRICTED_SETTINGS` имел значение `deny`; после `adb shell cmd appops set io.tvos ACCESS_RESTRICTED_SETTINGS allow` служба успешно включилась вручную.
- Для прошивок без нужного пункта меню описать этот способ через ADB как запасной вариант. Проверить повторное включение после OTA и перезагрузки.
- Пока только план для 1.1, без изменений кода текущего релиза.

## Стабильный запуск tvOS на AI POINT / CHiQ / MediaTek

- Исправить BootGuard: после холодной загрузки встроенный `com.mediatek.wwtv.tvcenter/.nav.TurnkeyUiMainActivity` иногда открывается поверх tvOS, хотя tvOS назначен главным экраном, а `RemoteKeyService` включён и подключён.
- Надёжно определять новую загрузку устройства вместо сравнения сохранённого `elapsedRealtime` с текущим: время запуска в разных загрузках не является идентификатором перезагрузки.
- Устранить использование обычных `SharedPreferences` для обмена состоянием между процессами `:home` и `:keys`; обеспечить актуальное общее состояние.
- Учесть позднее подключение службы специальных возможностей и порядок запуска TV Center. Пересмотреть ограниченное окно реакции в 12 секунд; одного увеличения таймера недостаточно.
- Сохранить доступность антенны / TV Center для обычного просмотра и поведение выхода из standby. Возврат на главный экран должен быть ограничен сценарием холодной загрузки, без циклического перехвата.
- Добавить диагностику причин активации, пропуска и результата возврата HOME. Проверить несколькими холодными перезагрузками, поздним подключением службы и выходом из сна на AI POINT.
- Конкретная причина данного сбоя не доказана: начало загрузки не попало в присланный лог; перечисленные дефекты обнаружены при проверке кода.
- Запланировано на 1.1; отдельную 1.0.3 для этого сейчас не готовить, код и опубликованную 1.0.2 не менять.

## Выбор жанра удержанием OK на постере

- Удержание кнопки OK на постере фильма открывает выпадающее меню с жанрами.
- Выбор жанра делает его активным фильтром и обновляет подборку: показываются фильмы выбранного жанра.
- Активный жанр должен быть виден в интерфейсе. Короткое нажатие OK сохраняет обычное действие открытия фильма; отпускание после удержания не должно одновременно открывать фильм.
- Пока только план для 1.1. Состав списка жанров (все жанры или жанры выбранного фильма) и способ сброса фильтра уточнить при реализации.

## Дополнительные идеи для 1.1 — приоритет и объём уточнить

- Центр управления: быстрый доступ к Wi-Fi, Bluetooth, звуку, заставке и переводу телевизора в сон. Совместимость управления питанием проверить на разных прошивках.
- Таймер сна: 30, 60 или 90 минут.
- Резервная копия настроек и пользовательских данных с переносом на второй телевизор.
- «Не интересно»: исключение нежелательных произведений из рекомендаций; отдельно от согласованной выше кнопки «Уже смотрел» для случайного выбора.
- Офлайн-подборки: сохранённые рекомендации и постеры при недоступном интернете; использовать существующий кеш изображений.
- Диагностика внутри tvOS: состояние приложения, память и экспорт отчёта без команд ADB.
- Персонализация профиля: возможность собственного фото и обсуждавшаяся интеграция Google-аккаунта; конкретный способ не выбран.
- Возможность использовать IMDb или Кинопоиск вместо TMDB: только исследование, решение о замене не принято. Сохранить совместимость ссылок с приложениями просмотра.

Переназначение кнопок, обновления и выполненные исправления заставок повторно не включены как новые функции.

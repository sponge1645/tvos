# План tvOS 1.1

Это список запланированных улучшений. Реализация отложена до отдельной задачи; в исправления 1.0.2 эти функции не входят.

## Интерфейс ближе к Apple TV

- Уменьшить отступы содержимого от краёв экрана.
- Использовать максимальную ширину Dock как ориентир для ширины и выравнивания основных блоков интерфейса.
- Сохранить удобство управления пультом и плавность на слабых телевизорах.

## Котировки на верхней панели

- Убрать виджет котировок с верхней панели: пользователь заметил ошибку его отображения.
- Запланировано на 1.1; в текущей версии ничего не менять.

## Приложение по умолчанию

Добавить «Настройки → Основные → Приложение по умолчанию», чтобы фильмы можно было сразу открывать в выбранном приложении без повторного выбора плеера.

## Продолжить просмотр

Продумать раздел с последними пятью фильмами или сериалами из каждого приложения, предоставляющего историю просмотра. В первую очередь проверить Seena и KinoPub. Показывать постер, название, сезон и серию; нажатие должно открывать нужное приложение и, при поддержке интеграции, продолжать с нужного места.

## Случайная карточка в категориях

- В конце всего списка постеров категории добавить постер с игральным кубиком и подписью «Случайный фильм».
- По нажатию этот же постер превращается в карточку случайного произведения из текущей категории: фильма в «Фильмах», сериала в «Сериалах», детектива в «Детективах».
- Выбирать только фильмы и сериалы с рейтингом 6,5 или выше.
- Добавить такую карточку во все категории, кроме «Новинок»; текущий перечень — «Фильмы», «Сериалы», «Детективы».
- Пока это идея для 1.1, без реализации в 1.0.2.

## «Уже смотрел» в режиме «Случайный фильм»

- Добавить к результату случайного выбора кнопку «Уже смотрел».
- Отмеченный фильм исключать из последующих случайных выборов, в том числе после перезапуска приложения и обновления tvOS.
- Хранить отметки в постоянных данных приложения отдельно от кеша постеров и подборок. Очистка кеша не должна удалять эту историю.
- Идентифицировать произведение по стабильному ID и типу, а не по локализованному названию.
- Включить историю отметок в будущую резервную копию. Полный сброс данных приложения удаляет локальную историю; восстановление возможно из резервной копии.
- Пока только план для 1.1.

## Дополнительные идеи для 1.1 — приоритет и объём уточнить

- Центр управления: быстрый доступ к Wi-Fi, Bluetooth, звуку, заставке и переводу телевизора в сон. Совместимость управления питанием проверить на разных прошивках.
- Таймер сна: 30, 60 или 90 минут.
- Резервная копия настроек и пользовательских данных с переносом на второй телевизор.
- «Не интересно»: исключение нежелательных произведений из рекомендаций; отдельно от согласованной выше кнопки «Уже смотрел» для случайного выбора.
- Офлайн-подборки: сохранённые рекомендации и постеры при недоступном интернете; использовать существующий кеш изображений.
- Диагностика внутри tvOS: состояние приложения, память и экспорт отчёта без команд ADB.
- Персонализация профиля: возможность собственного фото и обсуждавшаяся интеграция Google-аккаунта; конкретный способ не выбран.
- Возможность использовать IMDb или Кинопоиск вместо TMDB: только исследование, решение о замене не принято. Сохранить совместимость ссылок с приложениями просмотра.

Переназначение кнопок, обновления и выполненные исправления заставок повторно не включены как новые функции.

## Обновление локальных исходников

`tools/apply-source.sh` переносит снимок исходников в существующий проект,
создаёт резервную копию и сохраняет личную конфигурацию и файлы подписи.
Он также удаляет явно перечисленные устаревшие файлы, включая заменённые документы.
Скрипт нужен для используемой команды обновления проекта; это не механизм OTA APK.

История изменений и прежние отчёты доступны в Git. Файлы в `releases/` и `design/`
сохраняют материалы конкретных выпусков и интерфейса, а не заменяют текущее состояние.

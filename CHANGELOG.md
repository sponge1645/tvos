# Изменения tvOS

## 1.1.0-dev.41 — общая граница главной и Dock 5:3

- Главная использует общую сетку HomeLayout с внешней границей 40 px при 1920×1080: постеры/категории/погода по бокам, кнопки сверху/справа, Dock и нижняя погода снизу. Рулетка, уведомления и список приложений следуют той же сетке.
- Dock достигает прежней максимальной ширины 1840 px уже при шести приложениях. Плитки имеют пропорцию 5:3, максимум ≈253.33×152 px; высота подложки при шести — 232 px. При семи/восьми плитки уменьшаются пропорционально.
- Размеры/позиции слоёв согласованы с увеличенной высотой, чтобы не обрезать текст и анимации. Баннеры без отдельного логотипа обрезаются по центру, сохраняя пропорции на обеих Android-ветках; брендовые логотипы не растягиваются.
- Границы TalkBack списка приложений используют общую геометрию. Новый тест исполняет настоящие методы layout для 0–8 приложений, 64 комбинаций кнопок и 720p/1080p/4K.

## 1.1.0-dev.18 — обработка ошибок запуска приложений
